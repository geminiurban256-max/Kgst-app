# КГСТ — Расписание пар (PWA)

## Что это
Прогрессивное веб-приложение для просмотра расписания колледжа КГСТ.  
Работает офлайн, устанавливается на телефон как обычное приложение.

## Быстрый старт

1. Скачайте папку целиком.
2. Откройте `tools/make-icons.html` в браузере → нажмите кнопку → положите 3 PNG в `icons/`.
3. Загрузите папку на любой HTTPS-хостинг (GitHub Pages, Netlify, Vercel).
4. Откройте адрес на телефоне → «Установить приложение».

## Как развернуть на GitHub Pages (бесплатно, 5 минут)

1. Создайте аккаунт на github.com.
2. New repository → название `kgst-app` → Public → Create.
3. Add file → Upload files → перетащите все файлы из папки (включая подпапки `icons/` и `tools/`).
4. Commit changes.
5. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save.
6. Через 1–2 минуты сайт откроется по адресу `https://ваш-логин.github.io/kgst-app/`.
7. Откройте этот адрес на телефоне. Chrome покажет «Установить приложение» или через меню ⋮ → «Добавить на главный экран».

## Как развернуть на Netlify (тоже бесплатно)

1. Зайдите на netlify.com → Sign up.
2. Перетащите папку с файлами прямо в браузер на странице «Deploy manually».
3. Netlify выдаст адрес вида `https://random-name.netlify.app` — открывайте на телефоне.

## Почему нельзя просто открыть index.html

PWA требует **HTTPS** (или `localhost`) для:
- Service Worker (офлайн-режим)
- Установки на главный экран
- Чтения `manifest.json`

При открытии через `file://` всё это блокируется браузером. Поэтому нужен любой хостинг.

## Файлы

| Файл | Что делает |
|---|---|
| `index.html` | Разметка |
| `app.css` | Все стили |
| `app.js` | Логика: расписание, таймер, редактор, настройки |
| `manifest.json` | Данные PWA (имя, иконки, цвета) |
| `sw.js` | Service Worker — кэш для офлайна |
| `icons/` | Иконки приложения |
| `tools/make-icons.html` | Генератор PNG-иконок (открыть один раз) |
